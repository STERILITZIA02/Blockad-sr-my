# Changelog

本项目遵循语义化版本；发布日期以 GitHub Release 为准。

## 1.1.1 - 2026-07-26

### 新增

- 新增 GitHub Pages 固定安装页与 README 一键导入按钮，通过 Shadowrocket 官方
  URL Scheme 安装 `main/stable` 统一模块。
- 安装页不接受任意跳转参数，不加载第三方脚本，并提供手动唤起与原始订阅备用入口。

### 验证

- 自动检查安装页中的稳定 URL、URL Scheme、无开放重定向和无外部脚本约束。
- 本补丁不改变任何广告规则、Rewrite、响应脚本、MITM 主机或 Bilibili 排除边界。

## 1.1.0 - 2026-07-26

### 新增

- 将原 `AdBlock.module` 的 161 个软件分组逐项映射到当前执行路径；157 个分组已
  精确迁移、本地化替代或按安全边界部分迁移，Bilibili 由用户专用规则接管，
  3 个高误伤项逐项留档。
- 从 16 个核心组件扩展到 166 个 App/功能独立组件，并保持 2 个可能改变正常
  推荐/UI 的便利组件默认关闭。
- 新增腾讯新闻、百度贴吧、小红书、美团/大众点评、什么值得买、喜马拉雅、酷安、
  夸克、滴滴、酷我、薄荷健康等混合响应的本地强信号过滤。
- 新增机器可读 `audit/app-parity.json`、人工 `docs/APP_PARITY.md`、逐原模块
  `docs/ORIGINAL_MODULE_PARITY.md` 及固定上游二次核对记录。

### 更新

- QQ/腾讯新闻补齐 `adList` 和 `ad_list` 信息流过滤；京东补回直播推广小窗。
- 淘宝补入营销 PopLayer；微博补入当前实时/预加载开屏、第一方广告预加载和
  长文章广告位。
- 抖音补入第一方明确 `/aweme/v*/ad/` 与 `/api|motor/ad/` 路径；按用户要求从
  v1.1.0 发行物中完全移除 Bilibili Rewrite、脚本、组件和 MITM 主机。
- 补回经收窄的京东营销规则、滴滴活动通知、车来了含广告通知、向日葵启动推广、
  乐橙广告推送和华住弹窗；共享推送通道及正常通知保持不拦截。
- 发布前补入优酷、爱阅书香、悦Me TV、搜狗输入法、超级课程表、等等付和直播吧；
  混合配置/视频响应使用本地强信号过滤，不复活旧 IP 或共享视频 CDN 规则。
- 统一模块移除 46 条已被 AWAvenue 安全快照覆盖的重复域规则；独立 App 组件
  仍保留这些规则，单独启用时行为不变。
- 发行包加入完整迁移报告、上游研究、机器审计 JSON 和新增配置/测试源码。

### 安全

- 继续拒绝共享 CDN/图片尺寸、静态 IP、DNS/业务整域、更新/通知/账号接口等
  高误伤旧规则。
- 明确排除上游中的会员状态、皮肤、付费字段、播放地区、后台播放和下载权益修改。
- 123 个原远程脚本 URL 均未进入发布执行路径；所有响应处理仍为本地、幂等、
  有界遍历、失败开放且无外部请求。

## 1.0.0 - 2026-07-26

### 新增

- 将 11 个历史 Shadowrocket 模块审计为可复现的机器清单和人工功能矩阵。
- 新增统一模块、16 个 App/功能组件和 2 个默认关闭的便利组件。
- 新增本地 JSON 响应路由器，覆盖微信、京东、知乎、微博、闲鱼、高德和
  Bilibili 的明确广告结构。
- 固定并安全裁剪近期 Maasea YouTube Protobuf 处理器。
- 固定 AWAvenue 广告域快照，并排除 120 条登录、消息、支付、更新、正常媒体及
  共享业务高风险规则。
- 新增固定版本目录、稳定订阅入口、Release ZIP、SHA-256、安装、验收和回滚文档。

### 修复

- 修复高德旧模块把请求正则误写为第二个 `script-path=` 的确定性语法错误。
- 修复微博轻享版旧规则的 `^ttps?` 协议拼写。
- 移除 YouTube 未展开模板变量与全局 UDP/443 拒绝。
- 移除番茄小说的无效通配 DOMAIN、共享字节系域名和未验证静态 IP 封禁。
- 移除知乎通知、评论、账号、完整问题等正常接口拒绝。
- 去除同接口多脚本竞争、重复 MITM 主机和动态第三方 master 脚本依赖。

### 安全变更

- 不迁移会员、倍速、付费、支付、账户权益、皮肤或区域限制伪造。
- 不迁移会把用户搜索词发送到第三方站点的 `4in1.module` 行为。
- 不迁移需要在响应脚本内访问外部 Worker/豆瓣或上传日志的实现。
- 所有脚本在解析失败时保留原响应，不访问外部网络，不使用无限增长缓存。
