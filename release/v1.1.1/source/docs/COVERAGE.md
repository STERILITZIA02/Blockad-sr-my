# 覆盖范围、开关与已知边界

版本：1.1.1

审计基准：2026-07-26

第一支持目标：Shadowrocket

## 使用模式与真实开关

Shadowrocket 模块不能安全地用一套伪造参数 UI 条件拼装所有 section。本项目提供两种真实可维护的方式：

1. `dist/BlockAd.Unified.sgmodule`：默认组合，包含所有核心 App、通用广告网络和精确 PCDN/隐私规则。
2. `dist/components/*.sgmodule`：每个 App 或功能一个独立模块。只订阅需要的组件，即为独立开关。

两种方式二选一，不要把统一模块与其 components 重复启用。可选便利功能位于
`dist/extras/`，默认不并入统一模块。

## 保留的特殊与便利功能

- YouTube 上传按钮和选段按钮精简默认开启；Shorts 隐藏默认关闭；字幕改写默认关闭。
- 知乎链接去中转保留为 `dist/extras/zhihu-link-direct.sgmodule`。
- 闲鱼搜索、消息和个人页推荐精简保留为
  `dist/extras/xianyu-ui.sgmodule`，因为其中包含非广告推荐，默认关闭。
- 微信公众号阅读页广告区持续过滤。
- 高德首页/搜索 UI 仅删除带明确商业信号的项目，不再屏蔽天气。
- 精确 PCDN/隐私规则作为 `privacy-pcdn` 独立组件，并入默认统一模块。
- 151 个新增长尾组件均可独立启停；原软件名、旧规则、当前组件和取舍理由见
  `APP_PARITY.md`。

## 只归档、不进入稳定模块的旧功能

- `4in1.module`：把用户搜索查询发送到第三方索引站，既非去广告又改变用户意图。
- Bilibili 自动换区/豆瓣评分：旧上游没有声明 Shadowrocket 支持，主动请求豆瓣并修改区域限制字段；原文件仍在 `现有插件/` 供追溯。
- YouTube 画中画、后台播放、下载能力注入：属于账户/客户端权益能力改写，按安全边界移除。
- 微博非会员皮肤、迅雷会员、百度云倍速等权益改写：不属于去广告，明确不采用。
- 知乎全站 User-Agent 伪装：可能影响登录、验证码和页面布局，只保留链接直达。

## 缓存、证书与真机边界

- HTTPS 响应脚本必须在 Shadowrocket 中安装并信任 MITM 证书。
- 旧广告可能已经写入 App 本地缓存。首次启用后如仍看到旧开屏，可先完全退出 App，
  清除该 App 缓存（若 App 提供），再重新打开；后续匹配请求会持续过滤。
- 规则对冷启动、热启动、分页、刷新、前后台切换和配置重新拉取都按每次响应执行；
  不使用轮询或后台定时请求。
- 仓库只完成静态语法、构建、脚本 fixture、链接和发行包检查。没有声称完成 iPhone
  或 Shadowrocket 真机测试。
