# BlockAd SR v1.1.2

这是一次正常功能优先的回归修复版本。v1.1.1 的抖音组件把
`*.amemv.com`、`*.snssdk.com` 和共享素材域加入 MITM，导致抖音主视频流、下拉
刷新、评论等正常请求也进入 HTTPS 解密范围。该设计已撤销。

## 关键修复

- 抖音不再解密或改写 `amemv.com`、`snssdk.com` 主业务域；主视频流、刷新、
  评论列表、评论发布/点赞、搜索、个人页、直播和上传路径均加入负向保护测试。
- 穿山甲、Gromore 和 GDT 不再整域 `REJECT`。SDK 握手、配置依赖和日志连接可
  正常建立，仅对 `get_ads`、`settings`、`config`、`exchange`、
  `gdt_mview/view/click` 等明确广告载荷返回空响应。
- 修正穿山甲编号主机格式：使用
  `api-access.pangolin-sdk-toutiao1.com`，不再生成错误的
  `api-access1.pangolin-sdk-toutiao.com`。
- 友盟、Bugly、GDT、穿山甲和共享推送依赖从 AWAvenue 整域拒绝中排除，避免
  SDK 断连重试影响启动、通知或页面加载。

## 全仓安全收窄

- 统一模块、166 个独立组件和 2 个附加组件全部禁止通配 MITM；构建与发行检查
  会在以后发现任何 `*.` 主机时直接失败。
- 58 图片 CDN、爱奇艺图片 CDN、金山共享服务域、华米共享域、网易云音乐业务
  域、什么值得买图片 CDN、神州专车 CDN、菜鸟整域和其他旧通配规则均改为精确
  主机或撤下。
- 富途组件仍保留供单独选择，但因金融交易风险不再默认并入统一模块；其解密面
  也只保留 `api.futunn.com` 的明确 `/ad` 路径。

## 广告覆盖与诚实边界

抖音仍会阻断明确广告域、穿山甲/Gromore 广告载荷、落地页包和已验证广告素材。
由于不再解密抖音第一方主业务域，服务端混入或客户端原生的第一方 feed 推广可能
保留。这是为了恢复刷新、评论、发布、直播和播放稳定性而作出的明确安全取舍，
不能用宽泛 MITM 或整响应拒绝伪装为“全部去除”。
