# 11 个原模块审计基线

审计日期：2026-07-26

审计对象：`现有插件/` 下 11 个 `.module` / `.sgmodule` 文件

审计性质：静态审计与上游活跃度核验；没有声称完成 iPhone 或 Shadowrocket 真机测试

机器可读清单由 `npm.cmd run audit:legacy` 生成到
`audit/legacy-inventory.json`。每个文件均记录 SHA-256、section 计数、
接口匹配器、MITM 主机、外部脚本、未固定依赖和已检测风险信号。

## 总体结论

- 11 个文件合计不是“11 个单一脚本”，而是 9 个小型模块与 2 个大型聚合模块。
- `adultraplus.module` 单独包含 2,098 个 URL Rewrite、380 个脚本入口和
  118 个不同远程脚本 URL，是主要功能来源，也是主要冲突与供应链风险来源。
- `AdBlock.module` 含 264 个纯 Rewrite 入口，覆盖百余 App，但端点年代和
  拒绝响应结构不统一。
- 小模块中已经发现确定性错误：高德模块把匹配器写入 `script-path=`、
  微博轻享版存在 `^ttps?`、YouTube 模块包含未展开模板变量、番茄模块含
  不合法的通配 `DOMAIN` 和过宽共享域封禁。
- 现有模块没有提供激活状态，因此无法证明哪一个模块在用户设备上处于启用。
  迁移以“保留文件中可解释功能”为准；与广告无关或高风险的便利功能会保留为
  独立可选模块，而不会暗中混入默认核心。

## 已确认的特殊与便利功能

- Bilibili 港澳台番剧自动换区和豆瓣评分。
- YouTube 画中画、后台播放、字幕/歌词语言选项和可选 UI 精简。
- 知乎网页去中转链接与 UA 布局优化。
- 微信公众号文章广告区精简、微信外链处理。
- 多个 App 的热词/搜索建议净化、活动/营销入口隐藏、皮肤/推荐位精简。
- 番茄及部分聚合规则中的 PCDN、追踪和遥测拦截。
- Google 搜索到第三方模块索引的快捷跳转（保留为可选，不并入广告核心）。

## 已确认需要修复或替换的内容

1. 高德 5 个脚本入口使用重复 `script-path=`，导致匹配器不生效。
2. 微博轻享版一条规则写成 `^ttps?`。
3. YouTube 模块含 `{{{...}}}` 模板变量，不能直接订阅。
4. 番茄模块的 `DOMAIN,*novelapp...` / `DOMAIN,*default...` 写法无效。
5. 番茄对 `bytedance.com`、`zijieapi` 等共享基础设施的整域/关键词拒绝过宽。
6. 高德天气接口被当作广告拒绝，属于正常功能误伤。
7. 知乎通知计数、评论、账号和完整问题响应存在非广告误伤风险。
8. 大量远程脚本长期跟随 `main` / `master` 或无 revision 的 gist。
9. 聚合模块超大 MITM 列表和同接口多处理器增加性能、冲突和证书暴露面。

## 安全边界

整合阶段不会加入会员/权益伪造、付费破解、支付状态修改、Cookie/token 上传、
不明远程代码或未验证大网段封禁。对于无法可靠处理的客户端原生广告、
服务端拼接广告和本地旧缓存，将在 README 和最终报告中明确说明。
